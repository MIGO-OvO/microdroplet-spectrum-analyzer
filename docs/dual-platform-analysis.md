# 手动双平台与分段分析

适用于存在高、低平台，或文件中途因环境变化发生整体偏移的数据。

1. 加载文件后，在“分析横坐标范围”输入要分析的一段。若选了时间列，使用时间列的原单位；否则使用从 0 开始的有效数据点序号。起点、终点均包含，留空不限。区间至少含 3 点。
2. 在“平台识别方式”选择“手动高低幅度区间”，分别设置高、低平台的幅度上下限。可以上下拖动图中的四条边界线或标签，松开后参数同步到侧栏。标签获得焦点后，按上下方向键微调，Shift 加速；拖动中按 Esc 取消。低平台上限必须小于高平台下限，各自下限必须小于上限。拖动会限制边界顺序；直接输入无效区间时会提示修正。
3. 幅度窗口作用于去尖峰、平滑并减去“手动基线”后的处理信号。图中的绿色/蓝色区域分别表示高、低平台窗口。更改预处理基线后，应相应调整幅度窗口。
4. 按最短平台宽度设置“最小稳定长度”。手动模式按窗口内的连续数据点寻找平台，不使用自动模式的稳定性窗口、噪声/趋势容差和两态分离条件。边缘裁剪、离群剔除、去尖峰和参考配对参数仍有效。
5. 运行分析。所选范围在预处理之前截取，范围外的尖峰、平台和整体偏移不参与噪声估计、平滑、统计或参考配对。图、表、统计与导出均对应本次范围，坐标和数据点索引不重新从零编号。

拖动时纵轴保持固定，图中实时显示边界值。松开鼠标后，自动刷新开启时按现有的 350 ms 延时重新分析；关闭时点击“运行分析”。空白处拖动平移、滚轮缩放和双击重置仍可使用，调整边界保留横向缩放范围。

高低平台电平从原始信号区段内部作稳健测量，不以平滑值替代。每个**高平台**为测量对象：在高平台中心位置，由左右相邻且距离合格的**低平台**线性插值得到基线，**Δ = 高平台实测值 − 低平台基线**。缺一侧低平台时，可选择允许单侧参考；直接使用另一侧低平台电平，不属于插值，并带质量标记。建议把分析边界放在完整周期之间，以免裁断平台。

例如 L1 在 x=100 时电平为 0.0005，L3 在 x=200 时电平为 0.001，H2 在 x=150 时实测电平为 0.0348：基线为 0.00075，Δ 为 0.03405。低平台可以同时为左右两个高平台提供基线，并不是一对一消耗配对。

## 在界面复核

- H / L / U 分别表示高平台、低平台和未分类区段；后面的数字是本次分析的全局时序区段编号，不是分别从 1 开始计数。重新分析后编号可能改变。
- 主图横线表示检测区间，方块/圆点表示中心电平，Δ 竖线连接高平台实测值与低平台基线。选中高平台时，虚线连接实际左右低平台中心与基线计算点，不延伸至图框边缘。
- 点击图中区段或表格编号，主图定位并高亮，右栏显示对象、基线来源、计算位置、数值和质量标记。选择低平台可反查它服务的所有高平台。
- “高平台测量”只列出实际产生 Δ 的高平台；“全部检测区段”分页显示全部证据，包括未形成测量的高平台、未使用的低平台及未分类段，不再截断为前 200 段。
- “规则评分”是启发式评分，不是准确率或概率。手动窗口区段初始评分为 1，仅表示命中用户规则，不能证明稳定性或物理正确性。

## 波形和长度统计

结果表上方的“导出波形 CSV”保存本次分析范围内的全部采样点。CSV 为 UTF-8 BOM，包含 `time` 或 `sample_index`、
`original_signal`、`processed_signal` 三列；处理信号与主图一致，包含去尖峰、平滑和手动基线修正。
分析范围在预处理前截取，保留源文件坐标。图表缩放只影响显示，不改变 CSV 的数据范围和点数。
保存期间分析结果发生更新时，需用当前结果重新导出。

概览和 Excel 的 `Statistics` 工作表提供平均高平台长度、总体标准差与长度 RSD。
统计使用全部已分类高平台的检测点数，包含未形成液滴测量的平台，排除低平台和未分类段。
边缘裁剪后的有效点数属于电平测量，不作为平台长度。长度随平滑和检测参数变化，单位为采样点。

## 可信度与兼容性

原始电平稳健测量、拒绝不可分自动分类、配对距离限制和合成回归测试提供工程保障；尚无真实实验数据准确度验收。全局两态分类可能受明显漂移、多电平、稀有状态影响；平滑仍可能改变边界和被选中的测量点。局部线性插值不能保证消除非线性漂移。单侧、过大间距、噪声及未分类段标记均需人工复核。

程序使用双平台检测算法，旧单平台检测与寻峰入口已移除。CSV、XLS、XLSX 和时间列读取方式保持一致。旧历史记录仍保留原响应、统计与参数；重新载入或复用参数时，使用双平台算法重新分析，保留预处理和横坐标范围（跨文件复用时清除范围）。

旧工作曲线保留原始标定点与响应定义，仍可拟合、导入导出并反算浓度。平台平均高度、旧版低平台中心 Δ 和当前高平台减低基线 Δ 是不同的响应定义；跨定义反算会标为快速参考，新增标定点仍须使用同一响应定义。当前标定点保存 `responseDefinition: highMinusLowBaselineV1`，Excel 参数页也记录此定义。

若文件中间整体偏移，可先分析偏移前的范围，再修改横坐标范围与幅度窗口分析偏移后的范围。当前功能一次分析一个连续区间，不自动识别偏移点，也不把多个区域合并成一次结果。主图只显示所选分析范围；“恢复全文件范围”后重新分析可回到全文件。

原“自动稳定段分类”仍可选择，但严格稳定性判断可能排除缓慢变化的平台。手动窗口是用户给定的选择规则，不保证区段具有科学意义；请查看原始信号、区段长度、标准差和质量标记。无可配对高低平台时会明确提示，不输出伪造的测量值。

Excel 的 Droplet Results 表保存高平台与左右低平台 ID、电平、基线和 Δ，Stable Segments 表保存全部区段证据；Analysis Parameters 保存完整参数、响应定义及评分含义。PNG/SVG 绘制本次分析范围、手动幅度区域及高平台到低基线的 Δ。

工作曲线支持每个标定点独立的额外基线，使用方法见 [工作曲线说明](calibration.md)。同一文件的不同区间不视为独立重复，不能绕过同文件标定点去重规则。

验证使用合成信号，包括缓慢起伏、整体偏移、负幅度、非均匀时间轴、范围边界、预处理隔离和缓存切换，以及非对称高平台配对算例、缺失低参考、超远参考和新旧工作曲线隔离。界面使用合成预览复核，不能替代真实实验 CSV 的准确度验收。
