# v0.1.2

## 更新

- **处理后波形 CSV**：结果表上方点击“导出波形 CSV”，保存本次分析范围内的所有采样点。列为 `time` 或 `sample_index`、`original_signal`、`processed_signal`，保留源坐标和数值精度；处理信号包含去尖峰、平滑及手动基线修正。图表缩放不改变导出范围。
- **历史浓度**：历史页选择已保存工作曲线后，直接显示各记录的响应浓度及单位；选择在本机记忆。CSV 同时导出浓度、曲线名称、ID、更新时间、斜率、截距及计算状态。外推、负浓度、响应定义和处理参数差异按行显示；缺少响应或方程无效时留空并说明原因。
- **平台长度统计**：概览、历史记录和 Excel 提供高平台平均长度、总体标准差和长度 RSD。统计对象为全部已分类高平台，包含未配对高平台；长度使用完整检测范围的采样点数。无高平台留空，单个平台的标准差和 RSD 为 0。
- 本版包含此前的处理历史、图中拖动双平台幅度边界、图表与结果表联动复核、统一双平台检测引擎和 Windows 无控制台启动改动。旧数据文件、历史响应、处理参数及工作曲线保持可读。

## 安装

Windows 10/11 x64，简体中文 NSIS 安装器。运行需要 Microsoft Edge WebView2 Runtime，安装器不捆绑或下载该运行库。安装包未签名。
