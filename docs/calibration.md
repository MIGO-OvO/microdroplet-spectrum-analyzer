# 工作曲线与浓度计算

## 工作流

1. 在“数据处理”中导入并处理标准样品，等待结果同步。采集响应为所选分析范围内的平均高低差 Δ。旧曲线的平台平均高度或旧版 Δ 保持原样，新增标定点须与曲线使用同一响应定义，**一个文件只产生一个标定点**。
2. 切换侧边栏“工作曲线”，设置名称、浓度单位和权重。输入标准样品的已知浓度，点击“填入标定点”。同浓度的独立实验应使用不同文件名；同一个文件不允许重复加入。
3. 重复上述过程。至少两个不同浓度才能拟合；至少三个测量点才有残差自由度。浓度、额外基线和自定义权重可在表格中编辑，离开输入框后生效。每个点的拟合响应 = 采集响应 − 额外基线；采集响应始终保留，不随基线修改而累计扣减。已在数据处理中扣过的基线不要再次填入。旧曲线未记录额外基线时按 0 处理。
4. 草稿自动记忆在本机应用的 WebView 存储中。“保存曲线”将当前版本写入本地曲线库；编辑草稿不会改变数据处理面板正在使用的已保存方程，直到明确保存。更新现有曲线有确认提示。
5. “另存 JSON”保存当前曲线及其标定点、来源文件名、时间和请求处理参数，适合备份和迁移。“导入 JSON”始终追加副本，不覆盖原曲线或当前草稿。空草稿也可另存，但不能用于反算。
6. 反算浓度有两个入口：“数据处理”顶部的浓度条和“工作曲线”内的“样品浓度反算”。选择任意已保存曲线，按当前文件响应减去“样品额外基线”后反算。**不要求曲线的分析模式与当前数据一致**：曲线可以由平台检测的标定点建立、样品按液滴双电平分析处理，应用仍会代入计算，同时在结果旁并列显示两边的响应定义（如“平台平均高度”与“高平台 − 低平台基线 Δ”）并提示该值仅作快速参考。结果过期、分析中、加载中或没有有效结果时暂停反算。外推（包括负浓度）明确提示，不截断到零。当前处理参数与标定点不同或缺少来源参数时提示核对测量条件。
7. 使用“导出浓度 CSV”保留当前文件响应、反算值、单位、曲线版本时间、方程、外推标记、处理参数以及曲线与样品的响应定义是否一致。

**严格拟合、宽松代入。** 同一条曲线的标定点必须使用同一种响应定义，否则“填入标定点”和保存都会被拒绝——把平台高度与高低差 Δ 拟合进同一条直线没有物理意义。但读取浓度是另一个问题：用户往往只想快速知道当前信号对应多少浓度，因此任意已保存曲线都可以代入当前响应，定义不一致时只标注、不阻断。标注不能替代实验验证：不同响应定义之间的换算没有通用系数。

曲线库与草稿在重启后恢复，但不是独立备份：清理应用/WebView 数据、卸载软件或更换计算机可能丢失。请另存 JSON。读取损坏数据时不会自动覆盖原存储；写入失败会提示导出备份。数据均在本机处理，不上传网络。

## 数学定义

浓度为 x，扣除该点额外基线后的响应为 y。拟合带截距直线 y = a x + b，未知样品 x̂ = (y − b)/a；斜率为零时拒绝反算。对不同量纲/基线/实验条件的结果直接反算可能没有科学意义，应用不能代替实验条件验证。基线必须来自实验依据，不能仅为提高 R² 而调整。

默认 OLS 等权。可手动选择 1/x、1/x² 或自定义正权重 WLS；零浓度与倒数权重不兼容，应用不会自动排除空白或添加任意小常数。权重在计算时归一化至均值为 1，保存的是权重方案和用户权重。权重应反映响应测量方差的倒数，不能仅以提高 R² 为目标选择。

| 指标 | 定义及限制 |
| --- | --- |
| R² | 1 − Σwᵢeᵢ² / Σwᵢ(yᵢ − ȳw)²；WLS 明确标为加权 R²。响应恒定时不定义。 |
| RMSE | √(Σeᵢ²/n)，原始响应单位；不同权重的模型保留同一定义。 |
| 剩余标准差 | √(Σeᵢ²/(n−2))，原始残差；WLS 另列 √(Σwᵢeᵢ²/(n−2))。 |
| 残差图 | eᵢ = yᵢ − ŷᵢ，对浓度散点图，含零参考线；表格导出同时包含 √wᵢeᵢ。 |
| 截距 t 检验 | H₀: b=0，t=b/SE(b)，自由度 n−2，双侧 p；显著性水平 0.05。不自动改为强制过原点。标准误为零或自由度不足时不报告 t/p。 |
| 斜率 RSD | 100 × SE(a)/abs(a)，即单次回归的参数相对标准误，不是多次独立建立工作曲线的斜率重复性。 |
| 失拟检验 | 仅 OLS。k 个不同浓度，纯误差 df=n−k，失拟 df=k−2。SSPE 为同浓度独立测量对组均值的平方差和，SSLOF=SSE−SSPE，F=(SSLOF/(k−2))/(SSPE/(n−k))，报告上尾 p。至少 3 个不同浓度、存在独立重复且纯误差大于零才提供。 |
| RD | 100 × (x̂ᵢ−xᵢ)/xᵢ，每个测量点单独报告；零浓度不定义，显示“—”，导出留空。 |

t/F 推断依赖独立性、正态误差及正确方差模型。未知/估计的自定义权重引入额外不确定性，本实现将权重视为给定。经典失拟 F 检验不直接用于 WLS，面板会给出不可用原因；这不是“通过失拟检验”。同一文件中的多个平台不是独立标定重复。导入 JSON 的实验独立性必须由用户确认，文件名检查不能证明独立性。

本版本不自动检验异方差、不自动选择权重、不输出浓度置信区间或检出限，也没有默认的 RD 合格阈值；这些需要实验方案或验证规范支持。不要仅凭 R² 或 p≥0.05 判定曲线合格。

## 导出

- **SVG**：白底、黑色坐标与空心测量点、蓝色拟合线，无装饰网格；刻度向内、含轴标签及单位。可在矢量编辑器进一步排版。
- **PNG**：2400 × 1560 像素，使用与 SVG 相同的布局。未声明固定印刷 DPI；投稿时按目标物理尺寸换算，或优先使用 SVG。
- **残差图**：切换到残差图后，SVG/PNG 导出当前图，文件名带 residuals。
- **CSV**：UTF-8 BOM、第一行字段名、后续一行一个独立测量，规则矩形表。前八列是浓度、响应、归一化权重、预测响应、残差、加权残差、回算浓度和 RD，可直接用于 Origin；后续列保留来源与拟合信息。字符串元数据做公式注入防护，数值负号保留数值含义。
- **Excel**：桌面应用导出 .xlsx，Calibration 工作表先给出完整指标报告，再给出标定点表；数值为数值单元格，不是预格式化文本。
- 表格与图表导出使用**当前编辑版本**；数据处理反算使用**已保存版本**。图中方程作可读性舍入，计算始终使用完整精度。
- CSV/Excel 的 Response 为扣基线后的拟合响应；额外保留 Captured response、Additional baseline 两列，JSON 保存采集响应、基线及分析参数（含横坐标范围、高低幅度窗口）。

“论文风格”不代表通用 SCI 投稿标准；各期刊对尺寸、字体、DPI 和图例的要求不同，提交前需按目标期刊核对。
