# v0.1.4

## 界面

- 删除英文品牌副标题、重复检测标题、参数说明段落、图表操作小字和表格说明。
- 参数按分析范围、预处理和双平台检测分组；分析范围直接标明时间或数据点，空值显示“不限”。
- 图表保留信号与平台图例，缩放比例移至工具栏。选择平台编号后显示对应基线和测量详情。
- 工作曲线通过输入框、只读测量值和保存状态区分操作；历史页保留搜索、筛选、编辑与导出。
- 响应定义一致时直接显示浓度；定义不一致、超出标定范围、质量标记和计算错误仍随结果显示。

## 构建

推送 main 或手动运行 Windows build 后，GitHub Actions 执行前端与 Rust 测试，构建 Windows x64 NSIS 安装包，并保存安装包和 SHA256SUMS.txt。

Windows 10/11 x64，简体中文安装器。运行需要 Microsoft Edge WebView2 Runtime，安装包不捆绑运行库，未签名。

## 验证

- 前端 74 项、Rust 54 项测试通过；3 项手动性能基准未运行。
- TypeScript 与 Vite 生产构建通过。
- 在 640、1080、1600、2560 宽度检查数据处理、工作曲线和历史记录，页面无横向溢出，浏览器无脚本错误。
- 图表缩放与平台联动、曲线基线编辑与保存、拟合与残差切换、响应差异提示、历史搜索与编辑、浓度和 CSV 导出均通过交互验证。

全新系统安装与升级尚未验证。
