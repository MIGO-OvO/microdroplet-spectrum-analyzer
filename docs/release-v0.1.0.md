# v0.1.0

## 更新

- 完成 Python 到 Rust/Tauri + React 桌面工作台的迁移；运行安装版无需 Python。
- 优化自动区间：稳健噪声估计、连续信号段内部幅度、上下限两位有效数字及长度容差。
- 优化 20 万至 50 万点数据处理：CSV 流式读取、减少 Excel 字符串复制、分位数选择、预处理复用。
- 调参请求防抖与合并，结果表每页 100 条；导出仍包含全部检测结果。
- 局部放大读取更精细的数据；调整平滑窗口、过滤方式后保持缩放。
- 移除传统寻峰，保留平台检测；自定义标题栏取代 Windows 系统标题栏。
- 重写中英文 README，补充开发、打包、性能复现和算法限制说明。

## 安装

Windows 10/11 x64，NSIS 安装器，默认简体中文。
**不捆绑也不下载 WebView2 Runtime**；目标电脑需已安装该运行库。
安装包未签名。
