# v0.1.3

## 修复

- 默认使用手动高低幅度区间，平滑窗口为 51、最小稳定长度为 150 点、最长稳定长度为 0（不限）。幅度上下限可直接输入或在图中拖动。
- 移除“自动稳定段分类”、自动建议按钮及仅用于自动分类的稳定性窗口、噪声容差、趋势容差和两态分离控件。
- 加载文件时保留当前检测参数，清除分析横坐标范围。旧自动历史重新分析时改用手动窗口，并清除自动生成的长度上限；已保存的手动区间与长度上限继续按原值使用。
- 保留处理后波形 CSV、历史工作曲线浓度、平台长度统计，以及历史记录和工作曲线的原始响应定义。

## 原因

对用户提供的 141,946 点信号，同样设置平滑 51、最小长度 150，自动稳定性判断得到 0 个区段。
载入时的自动建议还会生成 194 点的最长长度上限；切到手动后该上限仍保留，而本文件 174 个高平台中只有 3 个不超过 194 点。
手动使用用户给定的幅度区间并将最长长度设为不限，v0.1.1 和 v0.1.2 均检出 174 个高平台、188 个低平台。
本版保留这一手动识别逻辑，修复默认配置及参数覆盖。

## 验证

- 前端 74 项、Rust 54 项测试通过；3 项手动性能基准未运行。TypeScript、Vite 生产构建、Rust 格式及 Clippy 检查通过。
- Windows v0.1.3 发布程序读取用户提供的 CSV，使用截图幅度区间检出 174 个高平台、188 个低平台，形成 168 个高平台减低基线 Δ 测量。区段、测量和统计与 v0.1.2 相同手动参数的结果完全一致。
- 全分辨率波形导出 141,946 点，截取 1000 至 20000 后导出 19,001 点；逐点回读核对原始信号、源坐标及处理信号，过期结果导出被拒绝。Excel 导出通过。
- 高平台平均长度 314.4770 点、总体标准差 148.0517 点、长度 RSD 47.0787%，与全部 174 个高平台逐段重算一致。
- 原生界面验证了旧自动记录复用和重新载入时清除 194 点上限、手动记录的 900 点上限保留、换文件保留检测参数，以及历史响应和参数原值保留。工作曲线浓度计算与历史 CSV 导出通过。
- 上述界面验证仅为文件对话框提供本机路径，数据读取、分析及文件导出均由程序原生命令执行。实验文件和验证导出留在本机。

平台数量对比尚无人工真值标注；干净系统的安装、升级及卸载未验证。
