# v0.1.1

## 更新

### 工作曲线与浓度计算

- 新增“工作曲线”面板：处理后的文件可按已知浓度填入标定点，一个文件只产生一个标定点，同文件重复加入被拒绝。
- 支持曲线草稿本地记忆、本地曲线库保存/编辑、JSON 备份与导入（导入始终追加副本，不覆盖原曲线）。
- 默认 OLS 等权回归，可选 1/x、1/x² 或自定义正权重 WLS；权重在计算时归一化至均值为 1。
- 诊断指标：加权 R²、RMSE、剩余标准差、残差图、截距 t 检验、斜率 RSD 与失拟检验（仅 OLS 且存在独立重复）。
- 调用已保存方程反算未知浓度，外推与负浓度明确提示且不截断；处理参数与标定点不一致时提示核对测量条件。
- 导出工作曲线与残差 PNG（2400 × 1560）、SVG，以及 Origin 可用的 CSV（UTF-8 BOM、含加权残差与 RD）和 Excel。
- 每个标定点可设独立额外基线；采集响应始终保留，不随基线修改累计扣减。
- 指标定义、WLS 与失拟检验的适用边界见 [calibration.md](calibration.md)。

### 手动双平台与分段分析

- 液滴双电平分析新增“手动高低幅度区间”，与原有“自动稳定段分类”并存；手动模式下不使用稳定性窗口与两态分离条件。
- 新增“分析横坐标范围”（含两端、可留空）：范围在预处理之前截取，范围外的尖峰、平台与整体偏移不参与噪声估计、
  平滑、统计和参考配对。
- 主图、结果表、统计与导出均对应本次范围，坐标与数据点索引保留原文件编号，不重新从零开始。
- 缓存键加入所选样本范围：切换范围会重建预处理，切换液滴判定参数不会。
- 无效范围、重叠幅度区间在命令层即被拒绝并返回中文原因，不输出伪造结果。
- 用法与边界见 [dual-platform-analysis.md](dual-platform-analysis.md)。

### 界面与导出

- 新增 100px 紧凑功能侧栏切换“数据处理／工作曲线”，880px 以下改为顶部横向导航。
- 图例与提示统一为“高平台／低平台”，手动模式下图中绘制高低幅度区域与边界线。
- Excel 增加 Analysis Parameters 工作表，保存本次完整请求参数与横坐标语义。

## 已知边界

- 手动幅度窗口是用户给定的选择规则，不保证区段具有科学意义；缓慢变化的平台仍可能被自动分类排除。
- 当前一次只分析一个连续区间，不自动识别文件中间的偏移点，也不把多个区域合并成一次结果。
- 工作曲线不自动检验异方差、不自动选择权重、不输出浓度置信区间或检出限，也没有默认 RD 合格阈值。
- 曲线库与草稿保存在本机 WebView 存储中，清理应用数据、卸载或更换计算机可能丢失，请另存 JSON。
- 图表导出为本次分析范围内的有界抽样，不是当前缩放视图；Excel 导出检测结果与参数而非原始信号。
